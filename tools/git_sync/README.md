# GitHub 双端安全同步工具（Windows / 中文）

本目录为 Smart Money AI Trader 的**独立开发维护工具**，用于比较本地 Git 仓库与远端 `main`，在风险可控时自动更新。工具不属于交易策略或交易执行链路，**不构成任何实盘交易功能验收**。

> 重要：**第一次**将本地尚未提交的主工程与已有 GitHub 仓库合并时，必须人工比较双方全部代码和文档，确认无遗漏、完成必要测试并正常提交。**本工具不负责首次无共同历史的自动整合。**

## 快速使用

在 GitHub 仓库根目录打开 `tools/git_sync/`，双击以下其中一个文件：

- **`SmartMoney_Audit_Only.cmd`**：备份与审计，生成中文报告；不合并或推送。
- **`SmartMoney_OneClick_Sync.cmd`**：备份与审计后，对安全情况自动快进、合并或正常推送；发现风险则停止。

默认自动识别本工具所在仓库根目录，无需填写个人电脑路径。如果工程目录不在默认位置，可以在启动前设置环境变量 `SMARTMONEY_PROJECT` 指定仓库根目录。

需要 Git for Windows、Python 3.11+ 及项目现有离线测试环境。前端变化时还需要 Node/npm 和已安装的前端依赖。

也可从仓库根目录执行：

```powershell
python tools/git_sync/smartmoney_sync.py --mode audit
python tools/git_sync/smartmoney_sync.py --mode sync
```

## 安全规则

| 情况 | 处理方式 |
|---|---|
| Git 提交已经一致 | 不执行额外更新 |
| 只有远端新增提交 | 安全快进，再运行离线测试 |
| 只有本地新增提交 | 敏感内容检查、离线测试通过后正常推送 |
| 两端各有提交且修改路径互不重叠 | 生成合并、通过离线测试后正常推送 |
| 同一路径两端均发生修改 | 停止，需人工逐文件检查 |
| 未提交文件、删除/重命名、不同 Git 历史、测试失败或可疑隐私文件 | 停止，生成中文报告 |

脚本不会执行强制推送、硬重置、自动清除文件，也不会按修改时间直接覆盖另一端。

## 备份和报告

每次执行会在**仓库同级**的 `SmartMoneyAITrader_SYNC_BACKUPS/<时间戳>/` 生成 `同步报告.txt`、Git 历史 bundle 和源码 ZIP 快照，并记录双方文件差异。备份目录不在公开仓库中。

**注意：源码快照不包含被排除的运行时目录、虚拟环境和超大文件，也不能代替真实账户数据库或敏感配置的单独加密备份。源码快照本身可能包含私密信息，请勿公开分享。**

本工具保护已提交的 Git 更新，但不保证能自动判断“不同实现哪一个功能更好”。涉及交易引擎、保护性订单或风控变动仍须人工检查和测试。脚本自带的敏感信息扫描也不等于全面的安全审计。

## 测试与状态

- 使用 `python tools/git_sync/test_scenarios.py` 可在**临时本地 Git 仓库**运行隔离场景测试，测试中不连接项目的 GitHub 远端。
- 基于 2026-11-04 版本的隔离验证覆盖 9 种场景：两端一致、本地领先、远端领先、无重叠合并、同名冲突、未提交修改、删除阻断、纯审计、疑似敏感文件阻断。
- **尚未在你的实际 Windows 主工程环境运行通过，不应把隔离测试当成主工程验收。**

本目录只用于项目维护；不要将内部工作记录、私人指令、用户资料、账户凭证或真实运行数据库提交到公开仓库。
