## 实际实现

2. 新增只读 `strategy/research.py` 与 `/api/research/indicators`。策略实验室可比较八币种、归档日内多个时点的指标、原入场条件和标准口径条件，并下载 JSON。数据是项目附带真实公开历史归档，非实时行情；不会更改会话、风险参数或订单。

4. 复核现有 Provider 军师/交易员与严格 Schema，覆盖越界比例、额外权限字段、错误动作和字符串比例拒绝。Pydantic AI 暂不引入；没有安装或声称验证该库本身。
5. 净值图拆为 `frontend/src/equity-chart.tsx` 与 `chart-data.ts`：时间排序去重、无效/未来数据排除、成交标记对齐、暂停时主题更新，以及条数不变时净值更新。无有效数据和图表失败有中文提示；保留初始线、目标线及署名。
6. 前端直接依赖固定现有版本；补充第三方许可、可选研究依赖和源码导出白名单。具体采用边界见 [组件审查](OPEN_SOURCE_AUDIT.md)。
