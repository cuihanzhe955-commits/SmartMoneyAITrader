## 用户下一步如何配合

打开设置页的“模拟平台联调准备 · 查看待办”。在“交易所账户”中保存自己的 OKX 模拟环境 API Key、Secret、Passphrase；在自动交易页创建 OKX 现货模拟会话，保持未启动即可。按照清单处理原单或资金阻断，再点击“运行模拟只读预检”。密钥不需要发送到聊天。

本页不能确认用户的账户/地区资格，也不能把 HTTP 成功或 Mock 通过当作平台成交验证。实际模拟下单、保护触发、取消、费用与重启联调仍是下一项待完成工作；真实资金验收继续要求单独明确授权。
