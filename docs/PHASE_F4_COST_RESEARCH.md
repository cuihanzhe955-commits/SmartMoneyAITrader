# F4 费用曲线与逐档成本研究

日期：2026-11-06；基于已上传的F1–F3文档检查点`fc1eea2`继续开发。该增量是只读研究，不是事件模拟账本或实盘下单。

## 实现

- 重新核验官方市场ID、明确的v1协议、结果Token/名称映射、费用开关、CLOB费用曲线和盘口规则。
- 只支持官方文档已核验的taker-only、指数1曲线：逐档费用估计为 `份额 × rate × price × (1-price)`。使用实时`fd.r`，不把`base_fee`的bps值直接当完整费率；不按币种类别写死系数。
- v2、未知版本、指数2等未覆盖曲线、缺少费用开关、结果映射或规则不一致明确拒绝，不回退默认公式。费用明确为零且曲线一致时才计算零费用。
- 按完整公开快照的卖盘逐档研究买入成本，计算预算、目标份额、数量向下取整、滑点上限、深度与费用的共同限制。返回取整前后目标、模型覆盖/未覆盖份额、名义金额、曲线费用、额外预留、剩余预算和每项限制原因。
- 数量研究步长为0.000001份；费用非零的每个研究档位额外预留0.0001参考USDC。这是保守研究预留，**不是平台实际收费或取整规则的声明**。
- 官方最小值同时作份额和名义金额的保守研究检查；原生最小值单位、抵押资产、真实扣费、gas及返佣尚未完成执行验收。因此`simulation_ready=false`、`execution_enabled=false`保持不变，即使研究门槛通过也不能提交订单或写入成交。
- 成本查询使用独立有界通道和3秒缓存，不阻塞盘口/结算查询或交易运行时；缓存不刷新源时间。

## UI操作

策略实验室 → Polymarket事件市场发现 → 查询公开详情 → 选择结果 → 展开「费用曲线与逐档成本研究」。填写目标份额、独立研究预算和最大滑点，点击「计算公开盘口成本」。结果明确区分曲线费用估计、额外取整预留及真实扣费未验证状态；修改输入或结果会清除旧成本显示。

## 测试与公开观察

- 全量隔离离线回归：**725通过、0失败**，32.34秒；新增成本测试33项。费用参考算例、逐档加权、预算/深度/滑点限制、显式零费用、拒绝错误单位或协议/曲线、缓存时效与账本不变均覆盖。
- TypeScript/Vite生产构建通过；Playwright实际打开临时服务，用合成数据检查成本输入、结果切换、费用/深度/结算、两档尺寸和深浅主题，无页面脚本错误。
- 真实公开只读样本市场6675981：v1，曲线系数0.05、指数1；20份额模型名义金额7.4、曲线费用0.2331、额外预留0.0001、总计7.6332参考USDC。**这不是平台成交、实际收费或可实现收益。** 盘口会变化，历史观察不能保证复现原价格。
- 没有账户读取、下单、资金兑付、数据库迁移或用户凭据修改。已有Starlette/httpx及前端构建提示保留，未引入新依赖。
