# 24小时翻倍挑战：策略模板集成

更新日期：2026-11-03。版本：1.0-C1-template-ui，开发检查点，尚非 Stable。

## 操作

1. 打开「策略实验室」，在「策略模板」中点击「使用挑战模板」。
2. 在自动交易创建表单中核对「策略模板：24小时翻倍挑战」、本金、环境和风险参数。也可直接打开自动交易，在创建表单的模板选择框选择挑战。
3. 默认本地模拟，规则引擎。勾选风险确认并创建后，仍需主动点击「开始运行」。
4. 在自动交易工作台查看倒计时、目标资金线、净值、持仓、决策和风控。可暂停、结束或紧急停止，结束后到实验报告查看独立报告。

侧栏中的独立挑战入口已移除。切换模板会重置未提交表单并恢复模拟环境，不会继承实盘确认或自动启动。已有未结束会话时，使用模板会回到已有会话并提醒先结束当前会话。

普通交易与挑战的内部 profile、会话编号、账本和报告保持原结构；未迁移或删除数据库记录。此轮未改变交易引擎、风险计算、交易权限或资金使用规则。
