## 实际变化

- terminal/runtime.py：独立 hosted 调度线程接入启停；仅在原库已有非终态保护意图时延迟打开恢复账本。与普通订单共用 order_mutex，成交事务与主状态共用运行锁；网络查询不持有主状态锁。
- execution/stop_recovery.py：按保护意图的原会话路由，校验当前密钥绑定、模拟环境和交易所账户身份，不因当前界面切换而改用其他账户。
- execution/live.py：保护意图未终结时阻止普通买卖提交；创建新会话和切换账户也受阻。托管触发子订单由专属通道处理，普通调度器不会重复处理。
- execution/stop_transport.py：增加可注入的提交锁，保护成交原子更新期间与主程序的账本写入串行。
- terminal/api.py、frontend/src/forms.tsx：新增只读维护状态接口与设置页状态区，显示线程、记录状态、数量、失败原因和普通委托阻断。明确仅模拟恢复、未自动创建、未通过真实资金验收。
- tests/test_stop_runtime.py：7 项新增回归；tests/acceptance_browser.py：增加真实 API 与新状态区校验。

没有增加创建保护单的 UI 按钮或开放真实资金写入。已有 demo 意图会自动恢复维护，普通用户启动后不需要运行额外命令。普通库无保护记录时不会自动创建保护表或访问额外平台接口。
