# Polymarket 公开研究使用说明

适用于F1–F4只读研究检查点。无需钱包、私钥、API Key；不是事件自动交易或模拟成绩页面。

## 在一个界面内查询

1. 启动本地工作台，打开「策略实验室」，找到「Polymarket事件市场发现」。
2. 选择开放或已关闭市场，设置每页数量、读取页数。关键词在本次有限样本内筛选；如果知道官方市场slug，可精确填写。点击查询不会创建会话。
3. 「查看市场标识」显示市场、事件、条件和两个结果Token；这些ID不能互换。
4. 「查询公开详情」展开当前市场，选择Up/Down或该市场实际返回的结果，点击「读取盘口与基准费率」。切换结果会清除上一结果的盘口显示。
5. 「查询官方结算」独立读取官方结算状态；要研究过去市场，先切换发现状态为已关闭，再打开详情。关闭市场也可能尚无最终兑付记录。

## 如何读结果

| 显示项 | 实际含义 |
|---|---|
| 元数据源更新时间 | 平台市场资料时间，不是当前盘口时间；缺少时显示未知 |
| 盘口源时间/接收时间 | 前者是平台快照，后者是本次接收；缓存不重置源时间 |
| 买一/卖一/深度 | 当前查询时快照，不是持续订阅或成交保证；仅显示前20档 |
| 基准费率bps | 官方参数；不是完整成交费率、返佣或收益测算 |
| 最小份额/价格档位 | 公开规则，不等于已验证账户余额或订单权限 |
| 已关闭 | 资料显示市场关闭，不等于已结算 |
| 官方API结算证据已核验 | 条件、最终状态、时间、兑付单位及向量通过检查；未进行链上核验或资金兑付 |
| 未确认结算 | 可能无记录、未最终结算、缺字段或时间/单位无法核验；不自动推断输赢或退款 |

元数据缓存30秒、盘口3秒、结算15秒，界面保留源时间和接收时间。只读研究当前不操作现货账户、交易预算、订单或持仓。

## 常见情况

- 查询0条：这是样本内没有匹配项，或映射/状态被拒绝，不证明全平台没有该市场。可调整关键词、页数或官方slug。
- 盘口过期/单边：不能使用旧价格冒充有效双边报价。换一个实际活跃的市场或稍后重新读取，不要为通过检查而修改时间。
- 限频/连接失败/地区拒绝：显示中文原因，不自动重试、切换域名或绕过限制。
- `resolved`但未确认：检查是否缺少完整兑付向量或完成时间。不能用市场价格接近0/1替代官方兑付。
- 费用模型、结算资产或模拟准备未通过：这是当前功能边界；后续费用与模拟模块完成前，不会在此页开启真实资金交易。

当前完整F阶段仍在开发。依据与测试见[只读实现记录](PHASE_F_READONLY_RESULTS.md)。

## F4费用曲线与成本研究

详情面板中展开「费用曲线与逐档成本研究」，填写目标份额、参考USDC研究预算及最大滑点，再点击计算。结果逐项列出预算与份额缩减原因，区分名义金额、曲线费用、额外取整预留和未覆盖份额。

仅支持明确v1、taker-only、指数1费用曲线。其他版本或未知参数会拒绝估算。每档额外预留及份额步长属于保守研究策略，不是实际平台收费/原生最小值单位验收；抵押资产、gas、返佣和实际成交未验证。研究门槛通过不会创建会话或订单。例子及测试见[F4记录](PHASE_F4_COST_RESEARCH.md)。


### 单位与费用精度

成本结果新增「单位与费用精度依据」：显示Gamma最小名义金额、CLOB原生单位未确认项、官方五位小数精度说明和逐档取整情景。该区间以每个研究档恰好一笔撮合为假设，不是实际费用范围；预算仍采用曲线费用和额外保守预留。规则缺失或三方参数不一致会拒绝估算，请重新查询，不能手动绕过。官方依据链接可直接在结果中打开。


## 保存研究证据

计算成本后点击「保存研究记录」。后端重新核验并保存实际快照，下方历史列表可刷新和查看完整证据；关闭并重启后保留。同一保存请求重试不会重复入库。记录是历史研究，不刷新原行情时间，不产生模拟成交或收益。操作和恢复边界见[F5.1记录](PHASE_F5_OBSERVATIONS.md)。


## 预测、参考模拟与Brain

1. 在公开发现结果中点击「用于预测研究」，市场与官方结果映射会自动带入下方。
2. 展开「创建独立研究会话」，填写参考资金、单轮预算、持仓数、优势和亏损阈值。规则价格基线不需要Key；AI使用已有AI设置中的模型，预测和复盘均受调用预算限制。
3. 选择是否引用记忆、是否生成有/无记忆配对预测。Brain引用开关也需开启；写入/引用/自动AI复盘可以分别控制。
4. 选择结果和本轮份额/预算/滑点，提交一轮研究。后台完成预测和独立风险检查，形成SKIP或明确标记的参考模拟持仓。
5. 官方结果可能晚于事件结束数分钟或更久；页面保持等待，不使用现货涨跌或价格接近0/1推断。暂停只停止新预测，已有轮次继续结算维护。
6. 查看轮次证据、配对评估和Brain来源，必要时纠错或导出。关闭软件后重启可继续；旧快照/提案不会重新当成当前信号。

详见[F验收](PHASE_F_RESULTS.md)、[Brain操作](BRAIN_MEMORY_DESIGN.md)。来源的simulation_ready=false仍不代表平台忠实模拟已准入；此页采用单独、显式的reference_v1_conservative成本假设，不能提交真实订单。


## 自动预测挑战（G1）

同一策略实验室下方可创建100轮预测挑战。程序逐轮发现、预测并等待官方结果，页面显示准确的预测/参与/SKIP/结算计数，支持暂停/恢复/结束和报告下载。此处进度百分比只针对当前挑战。通知通道仍待G2，操作与边界见[G1说明](PHASE_G1_CHALLENGE.md)。
