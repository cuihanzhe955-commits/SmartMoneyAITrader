# Polymarket 公开研究使用说明

适用于F1–F3只读开发检查点。无需钱包、私钥、API Key；不是事件自动交易或模拟成绩页面。

## 在一个界面内查询

1. 启动本地工作台，打开「策略实验室」，找到「Polymarket事件市场发现」。
2. 选择开放或已关闭市场，设置每页数量、读取页数。关键词在本次有限样本内筛选；如果知道官方市场slug，可精确填写。点击查询不会创建会话。
3. 「查看市场标识」显示市场、事件、条件和两个结果Token；这些ID不能互换。
4. 「查询公开详情」展开当前市场，选择Up/Down或该市场实际返回的结果，点击「读取盘口与基准费率」。切换结果会清除上一结果的盘口显示。
5. 「查询官方结算」独立读取官方结算状态；要研究过去市场，先切换发现状态为已关闭，再打开详情。关闭市场也可能尚无最终兑付记录。

## 如何读结果

| 显示项 | 实际含义 |
|---|---|
| 元数据源更新时间 | 平台市场资料时间，不是当前盘口时间；缺少时显示未知 |
| 盘口源时间/接收时间 | 前者是平台快照，后者是本次接收；缓存不重置源时间 |
| 买一/卖一/深度 | 当前查询时快照，不是持续订阅或成交保证；仅显示前20档 |
| 基准费率bps | 官方参数；不是完整成交费率、返佣或收益测算 |
| 最小份额/价格档位 | 公开规则，不等于已验证账户余额或订单权限 |
| 已关闭 | 资料显示市场关闭，不等于已结算 |
| 官方API结算证据已核验 | 条件、最终状态、时间、兑付单位及向量通过检查；未进行链上核验或资金兑付 |
| 未确认结算 | 可能无记录、未最终结算、缺字段或时间/单位无法核验；不自动推断输赢或退款 |

元数据缓存30秒、盘口3秒、结算15秒，界面保留源时间和接收时间。只读研究当前不操作现货账户、交易预算、订单或持仓。

## 常见情况

- 查询0条：这是样本内没有匹配项，或映射/状态被拒绝，不证明全平台没有该市场。可调整关键词、页数或官方slug。
- 盘口过期/单边：不能使用旧价格冒充有效双边报价。换一个实际活跃的市场或稍后重新读取，不要为通过检查而修改时间。
- 限频/连接失败/地区拒绝：显示中文原因，不自动重试、切换域名或绕过限制。
- `resolved`但未确认：检查是否缺少完整兑付向量或完成时间。不能用市场价格接近0/1替代官方兑付。
- 费用模型、结算资产或模拟准备未通过：这是当前功能边界；后续费用与模拟模块完成前，不会在此页开启真实资金交易。
