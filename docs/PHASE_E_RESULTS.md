## 本轮实现

| 子项 | 实际行为 | 验收边界 |
|---|---|---|
| E1 调度与取消 | 有界行情工作器、单客户端复用、600秒元数据刷新、请求剩余预算超时；独立发现和持仓保护工作器 | 网络调用只能协作取消；卡住的请求占用本通道唯一槽，不生成更多线程或排队；保护仍依赖其自身有效数据 |
| E2 动态模拟准入 | 批量公开行情、来源时间、搜索/名单、成交额、价差、异常涨跌与真实风险预算复核；分钟线及规则二次检查 | 只允许公开现货的 paper 会话；最小数量/金额、价格/数量精度与费用、滑点约束；成交额仅为流动性代理，未核验盘口深度 |
| E2 模拟生命周期 | 原固定池之外的候选可经规则/现有AI协调与独立风控进入模拟委托；下一根有效分钟线才可撮合；退出及结束结算同样校验规则 | 候选落选取消待成交买单；持仓和原单继续监控。规则不满足时保留持仓/残余，不用虚假成交清空 |
| E1 持仓保护 | 新增独立持仓分钟线通道；候选/发现挂起时仍能形成保护性卖单，并在下一根有效线模拟成交 | 本地模拟保护，非交易所托管；数据或规则无效拒绝撮合并显示状态 |
| E3 单主平台 | OKX/Binance/Gate 公开现货模拟可选；新会话独立预算、ID、账户作用域、订单、持仓和风控 | 已有会话未结束、任意环境未完订单、保护单或远程待核对资产时拒绝切换；不从旧平台搬运余额或订单 |
| E3 历史与重启 | 原会话完整归档；启动后保留主平台与账本；迟到结果不能进入另一个会话/平台 | 无数据库结构迁移，不重置用户运行数据；结束的模拟持仓仍留在原归档，不代表已平仓 |
| UI | 创建会话可选动态扫描及参数；设置和表单展示主平台/能力/切换阻断；雷达显示范围、监控和拒绝原因 | 不生成空按钮，不把表单选择当账户授权；Gate demo/live 不开放 |

## 验证结果

- CPython 3.12 / Windows 隔离离线回归：**587 通过、0 失败**；外部网络由审计钩子禁止。新增测试覆盖动态准入、真实风险预算、费用/取整、模拟成交、退出/结算、平台切换六个方向、远程遗留资产阻断、重启、慢发现、慢候选、地区拒绝及迟到结果。
- TypeScript 检查和 Vite 生产构建通过。依赖未变。保留既有的打包体积/依赖 use-client 提示和 Starlette/httpx 弃用提示，不为消除提示而更新依赖。
- Playwright 实际打开本地临时服务，使用明确标注的合成平台数据：1366×768 / 1920×1080、深/浅主题、动态配置、模拟启动、规则路径、主平台切换、Gate 无时间拒绝、无页面脚本错误。留存7张截图。截图不是平台联调证明。
- 公开探测与测试分开执行：不读取凭据、不访问账户接口、无订单写操作。OKX 466 对现货、104 对通过10 USDT研究筛选、BTC 245根有效收盘线；Binance 返回地区限制并停止；Gate 2032对、BTC244根收盘线，源时间缺失等原因使动态候选通过数为0。计数仅代表该时点。
- 新建独立 Python 环境，以本地已验收 wheelhouse 离线、逐哈希安装锁定依赖：版本校验、pip check、临时数据库初始化、服务启动、240根历史回放及安全停止通过；这不是干净 Windows 新机安装验收。原项目 `.venv` 版本不匹配、全局 Python 存在其他软件的依赖缺项，本轮均未修改。日后升级请使用项目一键安装器核对依赖。启动检查伴有 Windows Proactor/h11 连接关闭提示，功能断言及退出均通过；作为后续发布兼容性复核项保留。
- 自动化结果与公开探测摘要见 [E_TEST_RESULTS.json](E_TEST_RESULTS.json)。未进行干净 Windows 新机安装或真实账户测试。

## 操作与兼容

1. 创建会话 → 本地模拟 → 实时行情 → 选择主交易所 → 现货 → 入场候选来源选择「动态发现」。常用过滤、名单、扫描上限和滑点预算均在表单内。
2. 创建仅保存草稿配置，之后另行点击开始。普通会话可选规则或既有 AI 引擎；AI 仍需已有配置且必须经过风险和模拟执行复核。24小时挑战保留纯规则。
3. 切换平台先结束原会话，再创建新会话；设置页显示阻断原因。真实/demo 存在未核对资金或持仓时不能切换到模拟来掩盖它们。
4. 旧配置缺少 `market_mode` 时继续固定候选池。没有自动迁移旧会话到动态模式；旧账本和授权状态不复制到新会话。

## 尚未关闭的完整 E / Stable 门槛

- Binance 当前公开接口受地区限制；未绕过限制，也未证明当前环境能使用该平台。
- Gate 批量现货行情缺少源时间，动态入场保持拒绝；私有账户/订单/保护运行适配仍禁用。不能将通用 CCXT 协议 POC 当成该能力实现。
- 三所逐账户、逐产品的 demo 与真实订单/余额/费用/保护/恢复验收都未完成，沿用主计划的后移决定。
- 本地分钟线保护不能在程序退出、数据断流或规则不可验证时保证退出。当前没有新的交易所托管保护能力声明。
