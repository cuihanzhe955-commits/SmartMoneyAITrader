## 实际改动

- execution/hosted.py：新增事件记录时间。历史事件不回填推测时间，保留原有意图、订单和资金账本。
- execution/protection_report.py：按本地持久化事件生成只读核对报告，按事件 ID 分页，默认最近 100 条、最大 200 条；明确标记还有更早记录。报告提供当前状态的恢复建议以及既有账本中的成交量、金额、手续费折算、滑点和已实现盈亏。
- terminal/runtime.py、terminal/api.py：增加保护报告只读接口；读取在同一数据库快照内完成，不访问平台、不改授权。拒绝错误会话、未知保护单及非法游标；没有保护表时不自动初始化。
- frontend/src/forms.tsx、style.css：每笔保护记录可打开核对时间线、查看更早或最近记录、刷新并导出本页 JSON。打开期间自动更新，按唯一客户端标识维护组件状态，避免切换记录显示旧内容。界面数值适度舍入，导出保留原始值。
- tests/test_protection_report.py：新增 10 项测试，覆盖只读性、脱敏白名单、旧事件缺时、分页边界与不重叠、错误作用域、空库不建表、部分及全部成交费用。
- tests/protection_browser.py：浏览器操作扩展至报告导出，以及后台部分成交、费用入账、账户核对释放、剩余持仓保持暂停的交接闭环。

报告只输出显式允许的字段，不输出原始平台响应、API 凭据、账户绑定摘要或内部账户资料。报表中的当前平台联调和真实资金验证标记继续为 false。下载按钮明确导出当前页，不把分页结果冒充完整历史。
