## 1. 进度口径

此前沟通中的 25%–50% 是未定义权重的工程估算，没有可复核分母，不能作为正式完成率、发布就绪率或实盘验收通过率。后续按阶段、验收项和证据记录进度；**没有统一权重前，不使用单一百分比表示项目完成度**。

必须区分以下状态：

1. 已规划：主计划有要求，但尚无对应实现。
2. 已实现：源码中存在对应实现，不代表外部平台已经接通。
3. 离线测试通过：在隔离环境、测试替身或历史数据下通过指定测试。
4. 平台联调通过：有目标平台真实 demo 环境或受支持接口的可复核交互证据。
5. 真实账户验收通过：有经用户明确授权的真实账户订单、成交、费用、余额、退出和保护状态对账证据。

Mock、历史回放、公开只读行情、模拟成交、界面展示和文档声明均不能相互替代。
