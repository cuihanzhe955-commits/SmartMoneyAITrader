## 1. 进度口径

此前沟通中的 25%–50% 是未定义权重的工程估算，没有可复核分母，不能作为正式完成率、发布就绪率或实盘验收通过率。后续按阶段、验收项和证据记录进度；**没有统一权重前，不使用单一百分比表示项目完成度**。

必须区分以下状态：

1. 已规划：主计划有要求，但尚无对应实现。
2. 已实现：源码中存在对应实现，不代表外部平台已经接通。
3. 离线测试通过：在隔离环境、测试替身或历史数据下通过指定测试。
4. 平台联调通过：有目标平台真实 demo 环境或受支持接口的可复核交互证据。
5. 真实账户验收通过：有经用户明确授权的真实账户订单、成交、费用、余额、退出和保护状态对账证据。

Mock、历史回放、公开只读行情、模拟成交、界面展示和文档声明均不能相互替代。

**代码行为核对：**

- `MarketWorker` 采用单飞（single in-flight）方式，不建立无界请求队列；任务带有平台/会话作用域和有限截止时间。
- 网络请求在独立 daemon thread 中运行；行情 worker 不接收数据库或订单执行器对象。
- 支持协作取消、超时、作用域变化后的旧结果拒绝、返回数据深拷贝和错误信息脱敏。
- 后台 paper runtime 轮询结果，并在写入运行状态前再次核对会话版本和持仓版本。
- 暂停、停止、会话状态变化及关闭会使在途请求失效；旧请求未真正结束前保留唯一工作槽，避免并发堆积。
- 行情批次逐标的请求前检查取消状态和截止时间；公开行情客户端在请求结束后关闭。
- 对 HTTP 451 / 地区访问限制，运行时暂停自动扫描，不按普通网络错误盲目重试。

**新增测试用例覆盖范围（仅确认测试代码已提交，不代表已执行/通过）：**

- 慢行情请求不阻塞轮询，且请求队列不会增长；
- 平台/会话作用域变化时拒绝旧结果；
- 超时后拒绝迟到行情；
- 结果深拷贝并只交付一次；
- 异常响应不暴露 URL、请求头或密钥；
- 关闭与失效时协作取消，并在旧请求退出后才释放工作槽；
- 非法超时参数与线程启动失败处理；
- 后台 paper runtime 非阻塞获取、暂停后丢弃结果、超时后不写入账本、关闭不等待网络请求；
- 取消或超时后停止继续请求后续标的；
- 地区访问限制触发暂停且不自动重试。

**尚未验证：** 本次 GitHub 只读检查没有执行这些测试；没有 E1 最新全量测试报告，也没有 GitHub Actions 运行记录。E1 当前只覆盖后台公开行情模拟路径，不等于实时交易行情已验收，不等于动态候选已接入入场准入，也不等于多平台切换完成。源码清单记录版本为 `1.0-E1-public-paper-async`，`stable=false`、`real_funds_verified=false`。
