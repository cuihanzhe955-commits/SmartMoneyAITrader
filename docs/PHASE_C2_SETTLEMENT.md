# C2：触发子订单成交核对

2026-11-04；开发检查点。C 阶段仍未验收完成，整体进度粗估约 28%。

## 实现

- execution/hosted.py：新增 settle_children，将已确认触发的子订单、逐笔成交、费用、现金、持仓、资金曲线和保护状态原子写入现有 SQLite 会话账本。异常整笔回滚；禁止归属冲突、超预算、错币种、缺失子订单和重复认领。
- execution/stop_transport.py：新增只读成交收集流程，查询子订单和完整成交历史后交给账本处理，不提交新订单。
- tests/test_stop_settlement.py：12 项新增测试，覆盖全成交、部分成交撤销、手续费、重开连接恢复、重复读取、终态回报冲突、跨持仓归属及多子订单后续异常导致整体回滚。

子订单可能没有客户端编号：先由已确认的父保护单 ordIdList 绑定交易所订单编号，持久化实际客户端编号供后续一致性核对，使用独立内部账本编号调用原有结算器。成交唯一键仍采用真实成交 ID，不生成模拟成交回报。

部分成交撤销后剩余持仓仍保留。即使子订单完成，保护意图继续保持 TRIGGERED 并阻断替换；完整恢复、保护数量调整及释放条件要在后续独立验收，不能因已触发就认定已平仓。成功结算后清除入场核验状态，要求重新检查。
