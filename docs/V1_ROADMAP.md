# Smart Money AI Trader · v1.0 产品路线图

> 更新：2026-11-10。本文说明基础版本的产品目标和交付顺序；功能是否完成以当前源码和验收证据为准。

## 产品目标

打造 Windows 本地运行的 AI 辅助量化交易终端，优先支持数字资产**现货与永续合约**。模拟交易是开发和验证的优先方式；真实交易是正式产品能力，不能被模拟交易取代。

不承诺盈利。所有策略必须通过成本后回测、样本外和前向验证评估。

## v1.0 必须具备

1. **市场数据：** 实时/历史行情、盘口、成交量、交易规则、永续资金费率和数据质量检查。
2. **策略：** 可解释的趋势、动量、突破、均值回归和波动过滤策略。
3. **AI 决策：** 至少一条稳定、及时、可解释的 AI 分析与建议流程；有规则回退和明确错误状态。
4. **风险控制：** 仓位、单笔/账户风险、最大回撤、止损止盈、保证金和异常停机。
5. **现货交易：** 模拟和真实完整闭环。
6. **永续交易：** 模拟和真实完整闭环，包括多空、杠杆、保证金、资金费率和强平风险。
7. **回测与绩效：** 手续费、滑点、资金费率、净收益、最大回撤、样本外、Walk-forward 和前向模拟。
8. **账户与通知：** 资产、持仓、订单、成交、交易复盘、通知和异常告警。
9. **Windows 产品体验：** 清晰中文界面、安装、升级、恢复和安全配置。

## 实施顺序

| 顺序 | 目标 | 主要验收 |
|---|---|---|
| 0 | 本机与远端基线保全、集成阻断排查 | 所有工作树与未提交文件核对，已知失败复现，有回滚点 |
| 1 | 现货闭环 | 行情、策略、风控、模拟/真实订单、保护、成交对账和恢复 |
| 2 | 永续闭环 | 多空、保证金、杠杆、资金费、强平风险、模拟/真实执行和对账 |
| 3 | AI 可用性 | 模型连接、结构化建议、时效、成本、错误、回退和决策复盘 |
| 4 | 盈利验证 | 统一成本模型、样本外、Walk-forward、前向模拟和规则/AI 对照 |
| 5 | 产品整合 | 简化导航、保留已有功能、通知闭环、Windows 安装/升级/恢复 |
| 后续 | Polymarket、多角色 AI、高级优化和更多交易所 | 进入产品决策池，满足前置条件后逐项评估 |

## 开源优先

实现前先检查仓库现有代码和 GitHub 开源项目。适合时优先复用成熟库、适配器或独立组件，不要求每项能力从零开发。必须审查许可证、上游维护、Windows 兼容、依赖、安全、接口适配和回滚。详见 [开源组件评估](OPEN_SOURCE_AUDIT.md)。

## 验收规则

- 计划、源码实现、离线测试、平台联调和真实账户验收分别记录。
- Mock/历史回放/模拟成交不代表真实平台订单。
- 成本后净收益和样本外表现优先于单次回测收益。
- 任何删除或重大替换必须先列依赖和影响范围并获得所有者批准。
- 不得未经授权执行真实资金交易或提高风险权限。
