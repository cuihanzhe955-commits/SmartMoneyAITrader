# G1 自动预测挑战检查点

日期：2026-11-06；基线`2d55453`。G阶段仍进行，本检查点不代表通知通道、真实AI或真实资金验收通过。

## 本次实际实现

- 策略实验室新增100轮预测挑战面板，保留24小时纯规则模板与独立手动研究。
- 可配置目标轮次（默认100）、AI/规则基线、独立参考资金、每轮预算/份额、记忆引用、配对预测、亏损阈值、滑点、候选关键词/结束范围及扫描间隔。
- 公开发现按官方`endDate`排序、`end_date_min`筛选未来市场，每次最多3页×50条；仅选择开放v1、结束时间仍有效且未使用过的条件。样本不保证覆盖全部市场。
- 专属会话与持久轮次预约；每个条件最多安排一次，固定请求ID支持在预约/入队两侧中断恢复；禁止从手动API为挑战会话插入额外轮次。
- 逐轮等待官方结果后推进。有效SKIP可计入完成，失败、取消、过期或无效预测不凑目标；官方结果未知时不计已实现收益。
- 暂停新轮次、恢复、结束维护、报告导出；停止后不复活迟到的行情请求。已有轮次继续结算，账本不回滚。
- 分别统计安排、有效预测、参与、结算、有效完成、SKIP、失败、取消；方向正确率、参考交易胜率、连胜/连败、成本基础回撤。非二元兑付不计二元方向正确率；未参与不冒充成交。
- 关键参数不自动提高。AI配置缺失时不创建空挑战，预算不足或模型失败暂停；连续行情前置失败达到阈值暂停。亏损阈值不能通过恢复按钮绕过。
- 报告保留每轮模型、源时间、标识、概率、成本、费用/预留、滑点、参考现金、结算与拒绝原因。完整源证据仍按需读取。

## 兼容与可靠性修复

新增`prediction_challenges`、`prediction_challenge_rounds`表，复用F参考模拟与独立风控。新可选条件ID在执行前复核；旧F请求规范化后仍可幂等重试。

结算必须晚于模型实际完成预测时间；行情请求返回/报错时不能将已取消轮次复活。发现网络请求不持有交易锁或数据库事务，不阻塞现有结算/保护通道。用户原运行数据、凭据与真实资金权限未修改。

## 使用

策略实验室 → 100轮预测挑战 → 创建并启动自动挑战。AI模式需先保存现有AI配置；规则价格基线可不配Key。100轮AI通常至少100次预测，配对预测和复盘另计；当前每会话调用预算不足会暂停，需在设置中自行调整或减少目标，程序不擅自增加预算。

界面百分比仅指本挑战的有效完成轮次/目标轮次，不是项目总体完成度。结束会停止新增，保留未决记录继续维护；不要把等待官方结果当失败或零兑付。
