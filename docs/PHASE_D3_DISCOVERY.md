# D3 动态市场发现与预算研究

日期：2026-11-04。基线本地 `471dbea`；本轮 fetch 后远端 main 仍为 `bc51b68`。保留原主工程与运行数据，不进行真实账户联调或平台订单操作。

## 实际实现与文件

- `market/discovery.py`：独立无凭据 CCXT 公开客户端，加载目标平台的现货元数据，使用批量 ticker 接口。提供搜索、白名单、黑名单、成交额、24h振幅排序、价差、异常涨跌幅、软件最低金额、交易所数量/金额及手续费预算预检。没有逐币种行情轮询。
- 公开行情按平台缓存60秒、市场元数据缓存10分钟；同一实例并发查询只允许一个在途请求，其他查询明确提示忙碌。CCXT 原生限速开启，请求超时8秒、自动失败重试为0；失败不返回旧行情冒充成功，也不跨平台或换域名重试。
- 明确区分平台行情时间、后端接收时间、缓存年龄。缺失时间、过期行情、无效盘口或不完整规则被拒绝，成交额只作为流动性代理，不声称检查了实际深度或账户余额。
- `execution/market_rules.py`：从现有 Venue 提取共用现货规则校验；生产预检与研究使用同一套精度、活动状态、最小数量和金额上下限检查。`execution/venue.py` 改为委托该函数，原实际交易支持名单保持不变。
- Gate 的 CCXT 原生现货发现还会读取公开保证金交易对元数据。该信息不构成保证金授权；研究额外要求原始现货 trade_status=tradable 和明确 min_base_amount，不能让合并后的 margin/active 状态代替现货资格。禁止加载无关币种/链元数据，元数据请求数保持有界。
- `terminal/api.py`：新增本机 POST `/api/research/markets`。同步研究任务在独立请求工作线程执行，不持有交易运行时锁；没有访问凭据库或更改会话。程序退出时先停止原运行时，再释放研究客户端。
- `frontend/src/market-research.tsx`、`forms.tsx`：策略实验室新增中文研究面板，常用筛选可直接填写；展示发现/匹配/通过/显示数量、预算含费金额、拒绝原因与完整计算明细，包含加载、错误和空结果状态。入口初始不请求外部平台，用户点击按钮才查询。
- 新增 `tests/test_discovery.py` 和 `tests/discovery_browser.py`；源码清单、文档导航与版本元数据同步更新。

- **443 项全量隔离离线测试通过，0 失败**，比 D2 新增38项。保留既有 TestClient/httpx 弃用提示。
- 原生 CCXT 三平台元数据及批量 ticker 的 HTTP 拦截测试通过，验证只读请求路径与调用数量；Gate 无平台时间的测试报文被拒绝，不填造时间。
- 测试覆盖非原八币种发现、名单与搜索、数量显示上限、手续费预算、最小数量/金额、异常数据、过期/未来时间、失败不回退旧成功缓存、缓存两档 TTL、单请求去重以及研究不创建/修改交易会话。

## 采用范围与尚未完成项

**本轮完成动态发现研究与预算预检，不宣称完成动态自动交易扫描。** 原有运行中会话仍监控原数据池；没有把新币种自动加入交易，也没有启用 Gate 执行能力。实际自动交易候选/持仓保留、交易所切换隔离及资金授权仍需 E 阶段衔接和独立验收。

D 的图表性能/完整交易回放及全依赖供应链复审尚未关闭。C 的账户/资金验证仍按用户决定后移，不能标 Stable；未将增加的测试数换算为整体完成百分比。
