## 实际修改

- execution/hosted.py：撤销前必须重新查原单，确认仍为待触发且查询新鲜。请求次数和下次允许重试时间先持久化；按 30、60、120 秒冷却，最多三次。请求超时、重启或重复点击不会绕过次数和冷却。触发后禁止再次撤销父保护单。
- terminal/runtime.py：更新 Key、Secret 或 Passphrase 后按凭据摘要重建连接，失败不回退旧连接；连接按真实线程标识隔离，避免同名 API 工作线程共享连接。摘要和原始凭据均不返回 UI。
- 保护状态接口与设置页：区分手动模拟创建与自动创建，明确实盘创建关闭。待触发记录 15 秒未获得查询确认或本机时钟回退时显示过期；未知、撤销待确认和失败记录标记需处理。
- 保护交接展示实际剩余持仓、原保护数量及成交核对后的数量。释放后普通交易保持暂停，下一代保护采用实际剩余数量。界面提供先查单再重试撤销的操作，冷却中及达到次数上限时禁用。
- tests/test_stop_recovery_hardening.py：新增 14 项测试，覆盖有限撤销重试、重启后预算保留、触发竞态、状态过期、凭据更新、失败不回退、同名线程隔离及剩余持仓交接。
