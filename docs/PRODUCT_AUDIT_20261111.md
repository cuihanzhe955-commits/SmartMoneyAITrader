# SmartMoneyAITrader 产品与工程审计记录（2026-11-11）

> 来源：项目所有者提供的 GitHub Copilot 全面审计意见。本文记录审计结论及项目所有者采纳的决策。代码规模统计和部分 UI/架构观察未在本次文档更新中重新逐项计数，后续本机只读审计应复核。

## 1. 总体判断

项目已有相当数量的源码、测试、历史验收和阶段成果，但尚未收敛为低摩擦、可重复、可交付的最小产品。主要问题是范围偏宽、主线复杂、验证口径混杂、UI 偏向内部实现、AI 和盈利价值缺少可证明证据、并行工作树存在漂移。

本轮审计时远端 main 基线：`4dbda5fc797f87b45c258456ff16dcfad3ac126c`。该基线是开发集成检查点，不是 Stable；合并后请以 GitHub 最新 main 为准。

## 3. 产品与架构问题

- 模块范围横跨现货/永续、事件研究、AI、Brain、挑战、通知、回测和 Windows 发布，复杂度增长快于产品闭环验证。
- 生产交易、模拟交易、研究/事件市场和实验功能需要更清晰的边界，避免 UI 让用户误认为所有入口均已验收。
- 不同日期的测试数字对应不同范围和时点，不应简单视为同一口径。必须指定当前事实源，历史报告标注为历史证据。
- 用户界面应围绕常用任务组织，而不是围绕内部模块数量组织。
- 并行代理必须限制为一个活跃写入者，避免工作树、分支和文档漂移。

## 4. UI 收敛建议

主导航目标为：首页、运行、历史、设置。首页聚合运行状态、模拟资产、净值、收益、回撤和风险告警；运行页完成市场/策略选择与纸面会话控制；历史页展示订单、成交、费用、净值、回撤和导出；设置页管理数据源、策略、可选 AI 与风险上限。

研究、事件预测、通知、Brain、G1/G2、实验报告和诊断能力默认不删除；在 v0.1 中移至实验区、二级入口或隐藏导航。UI 收敛不授权删除后端模块、API、数据库表、历史数据和测试。

## 5. AI 结论与采纳方式

当前 AI Provider 可证明的是兼容接口调用和结构化输出校验，不等于交易判断有价值。

v0.1 AI 默认关闭。开启后仅解释规则信号、列明风险或复盘历史交易；不直接创建订单，不改变规则信号，不绕过确定性风控。界面显示 Provider/模型、延迟、估算成本、错误和回退状态。

后续使用固定 100–300 个样本，保存行情快照、提示词/模型版本、输入输出、延迟和成本；与纯规则基线比较一致性、可解释性和成本，再通过同数据、同费用口径的 A/B 与样本外测试决定是否扩大 AI 决策范围。JSON 合法或 Mock 通过不能证明 AI 有交易价值。

## 6. 盈利能力结论

当前没有足够证据证明策略盈利。动量、趋势、相对量能、突破、波动率和 RSI 等启发式组合只能作为研究基线。

后续研究至少包含时间顺序训练/验证/样本外切分、买入持有与不交易基准、手续费、滑点、最小成交单位、永续资金费率、交易次数、胜率、盈亏比、Profit Factor、Expectancy、最大回撤、收益波动、市场状态、参数敏感性、消融实验、AI/规则 A/B 和失败区间。禁止未来数据泄漏。

在完成以上证据前，项目定位应为量化交易研究/模拟工具，不宣传为赚钱工具，不承诺收益。

## 7. 发布与协作风险

- 938 项离线回归是历史工程证据，不能代替浏览器、Windows 干净安装、平台 demo 或真实账户验收。
- 较早提交 `d64371abfcef4ebdbd71d05a62ebe0e6ce6ab57d` 的 Windows paper regression 曾记录 **937 passed / 1 failed**。失败测试为 `tests/test_component_audit.py::test_published_audit_matches_exact_dependency_inputs_and_known_advisory_results`，报告原因是 `docs/DEPENDENCY_AUDIT.json` 中的 npm lock SHA 与 `frontend/package-lock.json` 当时内容不一致。后续提交 `40f47c3f58a31eab8786016b8e29320112b7f527` 曾触发 Windows paper regression run #5（当时离线回归步骤仍在运行）；后续 PR HEAD 的检查状态请以 [PR #2 Checks](https://github.com/cuihanzhe955-commits/SmartMoneyAITrader/pull/2) 为准。历史测试记录不能替代最终 HEAD 验收；必须重新执行依赖审计并验证，不能只手改 SHA、降低测试或跳过测试。
- 其他已知集成阻断：保护单浏览器流程超时、86,401 点图表压力内存失败、G1 Worker 遇 Brain 数据库 busy 后退出、浏览器验收存在 ConnectionResetError。
- 当前本机工作树信息来自 2026-11-10 历史审计；Copilot 开发前必须重新核验，不得将历史 SHA 当成实时状态。
